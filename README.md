# Finance Dashboard

Sistema web de controle financeiro pessoal, desenvolvido como projeto acadêmico.

## Sobre o projeto

O Finance Dashboard tem como objetivo permitir que usuários gerenciem suas finanças pessoais, acompanhando receitas, despesas e saldo financeiro por meio de uma interface simples e intuitiva.

## Tecnologias utilizadas

- HTML
- CSS
- PHP
- MySQL
